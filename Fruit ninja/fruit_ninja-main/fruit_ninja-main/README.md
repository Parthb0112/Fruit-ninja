# 🍉 Kawaii Fruit Ninja CV

A webcam-based hand-tracking fruit slicing game built with Python, OpenCV, and MediaPipe. 

## 🛠️ Prerequisites
* Python 3.8+
* A functioning webcam
* Required Python packages: `opencv-python`, `mediapipe`, `numpy`

## 🎮 How to Use

**1. Install Dependencies**
```bash
pip install opencv-python mediapipe numpy

```

**2. Run the Game**

```bash
python fruit_ninja_cv.py

```

**3. Controls**

* **Slice:** Stand back and move your index finger in front of the webcam.
* **Restart:** Press **`R`** when you run out of lives (bombs cost lives!).
* **Quit:** Press **`Q`** or **`ESC`** at any time to exit.
